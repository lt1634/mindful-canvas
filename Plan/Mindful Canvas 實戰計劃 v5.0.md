## 1. 產品定位

### 一句話

用觸覺繪畫 + AI 情緒解讀，幫中學生用「畫」代替「講」來處理壓力。

### 唔係乜

- ❌ 冥想 App（Calm/Headspace 留不住人）
- ❌ 繪圖工具（Procreate 門檻太高）
- ❌ 心理治療 App（醫療合規紅線）

### 係乜

- ✅ 情緒出口（5 分鐘內完成，零壓力）
- ✅ 正念練習工具（融入課堂，唔係額外活動）
- ✅ 學生自我覺察輔助（唔需要心理學背景）

## 2. 用戶旅程（User Journey）

### 2.1 完整流程

```
學生掃 QR Code
    │
    ▼
┌─────────────┐
│  歡迎頁面   │ ← 4 個情緒場景 + 引導語
└──────┬──────┘
       │ 揀一個場景
       ▼
┌─────────────┐
│  繪畫畫布   │ ← 手指塗抹 + 選色 + 換筆刷
│  （5 分鐘） │ ← 線條慢慢消失（無常效果）
└──────┬──────┘
       │ 同時可以說話（語音輸入）
       ▼
┌─────────────┐
│  按「完成」 │ ← 系統計算統計數據
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  AI 解讀    │ ← 生成禪意題字 + 心境解讀
│  （2 秒）   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  心靈卡片   │ ← 原始畫作 + 題字 + 解讀
│             │ ← 一鍵儲存為手機壁紙
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  反饋問卷   │ ← 3 條問題（1 分鐘）
└─────────────┘
```

### 2.2 關鍵時間指標

- 掃碼到開始畫：< 10 秒
- 畫畫時間：用戶自主（平均 3-5 分鐘）
- 生成卡片：< 2 秒
- 儲存卡片：< 3 秒
- 填反饋：< 1 分鐘
- **總體驗時間：< 10 分鐘**

## 3. 功能規格（Feature Spec）

### 3.1 歡迎頁面

| 項目         | 規格                                            |
| ------------ | ----------------------------------------------- |
| 場景數量     | 4 個                                            |
| 場景列表     | 焦慮、混亂、卡住、自由書寫                      |
| 每個場景包含 | emoji + 標題 + 20 字描述 + 引導語（toast 顯示） |
| 互動方式     | 點擊即開始，唔需要登入/註冊                     |
| 設計原則     | 暗色背景、金色 accent、極簡                     |

**場景引導語（進入畫布時 toast 顯示 5 秒）：**

| 場景 | 引導語                                                                                         |
| ---- | ---------------------------------------------------------------------------------------------- |
| 焦慮 | 深呼吸……這張白紙是一片安靜的雪地。你的畫筆只是輕輕劃過表面。不需要急著定義它。                 |
| 混亂 | 腦袋裝了很多東西，像一團打結的線條。沒關係，不需要強迫它停下來。把混亂透過畫筆引導到紙上。     |
| 卡住 | 停滯是創作中自然的一部分，像音樂裡的休止符。不要想「我要畫什麼」，而是感受「我的手想怎麼動」。 |
| 自由 | 沒有規則，沒有對錯。讓手帶領你，讓色彩在畫布上流動。這一刻，你只需要與色彩同在。               |

### 3.2 繪畫畫布

| 項目     | 規格                                 |
| -------- | ------------------------------------ |
| 技術     | HTML5 Canvas + Touch Events          |
| 解析度   | 跟隨設備 DPR（devicePixelRatio）     |
| 顏色     | 8 色禪意調色盤（見下表）             |
| 筆刷     | 4 種大小（2px, 4px, 8px, 14px）      |
| 無常效果 | 每 3 秒重新渲染，舊筆觸 opacity 遞減 |
| 筆觸樣式 | round cap + round join（自然手感）   |

**禪意調色盤：**

| 名稱 | 色碼    | 用途           |
| ---- | ------- | -------------- |
| 金光 | #e2b55a | 主色、温暖智慧 |
| 深海 | #2c5f7c | 沉澱、平靜     |
| 暮色 | #8b5e83 | 直覺、轉化     |
| 枯葉 | #a0826d | 穩定、根基     |
| 霧白 | #d4d0c8 | 留白、可能性   |
| 翠竹 | #5a7a5a | 成長、療癒     |
| 晚霞 | #c46b4a | 熱情、生命力   |
| 墨色 | #3a3a4a | 深沉、內省     |

### 3.3 語音輸入

| 項目 | 規格                                 |
| ---- | ------------------------------------ |
| 技術 | Web Speech API（瀏覽器原生）         |
| 語言 | zh-HK（粵語）/ zh-CN（普通話）       |
| 模式 | 按住說話（toggle），支援連續辨識     |
| 顯示 | 即時顯示辨識文字（interim + final）  |
| 降級 | 不支持嘅瀏覽器顯示提示文字，唔 crash |
| 成本 | $0（瀏覽器內建）                     |

### 3.4 AI 情緒解讀（v1 模板引擎）

| 項目     | 規格                                              |
| -------- | ------------------------------------------------- |
| 輸入     | 場景 + strokeCount + totalSilence + dominantColor |
| 輸出     | 題字（1-2 句）+ 解讀（100-200 字）                |
| 題字庫   | 每個場景 3 句，隨機抽取                           |
| 解讀模板 | 每個場景 1 個模板，動態插入統計數據               |
| 語言風格 | 繁體中文，溫和、包容、唔說教                      |
| 成本     | $0（純前端）                                      |

**解讀模板結構：**

```
你剛才畫了 {strokeCount} 筆，
{silence > 5 秒 ? "其中有 {silence} 秒你完全靜止了，那是你與自己對話的時刻" : "節奏流暢"}
。{scene_specific_reflection}。
每一筆的消逝，都帶走了一小部分重量。你做得很好。
```

### 3.5 心靈卡片

| 項目     | 規格                                                              |
| -------- | ----------------------------------------------------------------- |
| 尺寸     | 1080 x 1440 px（手機壁紙比例）                                    |
| 結構     | 上半：原始畫作 / 中間：禪意題字 / 下方：心境解讀 / 底部：品牌標識 |
| 背景     | #1a1a2e（深藍黑）                                                 |
| 輸出格式 | PNG                                                               |
| 儲存方式 | Canvas → dataURL → download link                                  |
| 成本     | $0                                                                |

### 3.6 反饋問卷

| 項目     | 規格                                                                |
| -------- | ------------------------------------------------------------------- |
| 問題數量 | 3 條                                                                |
| 問題     | 1. 開心指數 1-10 / 2. 會唔會想再玩 是/否 / 3. 有乜嘢想改進 自由文字 |

## 4. 數據收集框架

### 4.1 v1 收集嘅數據（全部前端 localStorage）

| 數據項        | 類型    | 說明             |
| ------------- | ------- | ---------------- |
| sessionId     | string  | 每次體驗唯一 ID  |
| scene         | string  | 揀咗邊個場景     |
| strokeCount   | number  | 畫咗幾多筆       |
| totalSilence  | number  | 停頓幾多秒       |
| dominantColor | string  | 最常用嘅顏色     |
| voiceUsed     | boolean | 有冇用語音       |
| voiceText     | string  | 語音文字內容     |
| duration      | number  | 總體驗時間（秒） |
| satisfaction  | number  | 開心指數 1-10    |
| wantAgain     | boolean | 會唔會想再玩     |
| feedback      | string  | 自由文字反饋     |
| timestamp     | string  | ISO 時間戳       |

### 4.2 數據分析（Phase 1 用 Excel 就夠）

每週 exported 一次 localStorage 數據，用 Excel 分析：

| 指標         | 計算方式                                    | 目標                   |
| ------------ | ------------------------------------------- | ---------------------- |
| 平均滿意度   | AVG(satisfaction)                           | ≥ 7/10                 |
| 再玩意願     | COUNT(wantAgain=true) / COUNT(all)          | ≥ 70%                  |
| 平均體驗時間 | AVG(duration)                               | 3-8 分鐘               |
| 場景分佈     | COUNT(scene) GROUP BY scene                 | 了解邊個場景最多人揀   |
| 語音使用率   | COUNT(voiceUsed=true) / COUNT(all)          | 了解學生對語音嘅接受度 |
| D7 留存率    | COUNT(unique users returning within 7 days) | Phase 2 先計算         |

### 5.4 模塊化拆分計劃

**v1 → v2 拆分步驟：**

1. 從 `index.html` 拆出 `canvas.js`（繪畫邏輯）
2. 從 `index.html` 拆出 `voice.js`（語音模組）
3. 從 `index.html` 拆出 `card.js`（卡片生成）
4. 從 `index.html` 拆出 `ai.js`（AI 解讀）
5. `app.js` 保留路由 + 狀態管理
6. 新增 `api.js` 處理前後端通訊

**每個模塊嘅接口定義（v2 時建立）：**

```javascript
// canvas.js
export function initCanvas(container) → void
export function getStrokeData() → { strokeCount, totalSilence, dominantColor, strokes[] }
export function clearCanvas() → void
export function getCanvasImage() → dataURL

// voice.js
export function initVoice() → void
export function startRecording() → void
export function stopRecording() → string (transcript)
export function onVoiceResult(callback) → void

// card.js
export function generateCard(drawing, interpretation) → dataURL
export function downloadCard(dataURL) → void

// ai.js
export function interpret(scene, strokeData, voiceText) → { affirmation, reflection }
// v1: 模板引擎
// v2: Ollama API
// v3: Claude API
```

## 6. Prompt 模板（AI 解讀算法）

### 6.1 System Prompt（v2 用，接 Ollama）

```
你是一位擁有 10 年以上資深經驗的視藝教育家、藝術評論家，同時也是一位深諳東方佛學與表達藝術治療（和諧粉彩/正念）的靈魂導師。

你的語氣溫和、包容、充滿藝術氣息與詩意。
【絕對避免】使用任何宗教教條、陳腔濫調的說教，或過於商業化的療癒系口吻。
你說話的目的是給予用戶深度的陪伴、澄清與溫柔的轉念。
請用繁體中文/粵語混合的港式文風輸出。
```

### 6.2 User Prompt 模板（v2 用）

```
用戶情緒狀態：{scene}
用戶情緒文字：{voiceText}
繪畫統計：共 {strokeCount} 筆，停頓 {silence} 秒，主要色彩 {dominantColor}

請生成：
1. 【禪意題字】（1-2 句話）：將用戶的焦慮或壓力文字提煉為充滿力量的禪意題句
2. 【心境解讀】（150-200 字）：結合繪畫統計進行客製化解讀，結構：點出筆數 → 解讀停頓意義 → 色彩與情感連結 → 將線條消失引導至無常與放低執著 → 一句溫柔讚賞
```

### 6.3 安全守則

```
如果用戶情緒文字包含自殘/自殺傾向詞語：
→ 立即停止常規解讀
→ 輸出：「我聽到你了。你不是一個人。」
→ 顯示：香港 24 小時生命熱線 2382 0000
→ 不顯示卡片，不收集數據
```

## 10. 成功標準（明確停損線）

### 90 日後，如果以下任一條件成立 → 繼續

1. 有學生主動問「幾時再畫？」
2. 有同事問「可唔可以用喺我個班？」
3. D7 留存率 > 20%
4. 有家長表示有興趣

### 如果以下全部成立 → 停止

- 冇學生主動提起
- D7 留存率 < 10%
- 冇同事/家長反饋
- 你覺得呢件事冇帶來價值

**停損唔係失敗，係智慧。將時間投入回報率更高嘅事情。**

## 11. AI 協作指南

```
幫我改 mindful-canvas 嘅 [某個畫面]，具體改 [乜嘢]。

```
幫我加一個 [功能名] 到 mindful-canvas。
需求：[詳細描述]
