## 一、核心定位（一句話）

**用觸覺繪畫 + AI 情緒解讀，幫中學生用「畫」代替「講」來處理壓力。**

唔係冥想 App（留不住人），唔係繪圖工具（門檻太高），係一個**情緒出口**。

---

## 二、點解呢個方向值得做

### 市場缺口

- 全球心理健康 App 市場：$99 億（2025）→ $227 億（2030），CAGR 15%+
- Calm/Headspace D30 留存率 < 5%，因為靜態冥想對高焦慮者無效
- 香港中學生壓力指數全球前列，學校有 Well-being 需求但缺工具

### 你嘅 Specific Knowledge（AI 無法複製）

- 10 年視藝教育經驗
- DSE SBA 考官級評審眼光
- 佛教學校背景 — 正念唔係外加嘅，係你日常教學嘅一部分
- **呢三樣嘢組合出嚟，全香港冇第二個**

### 渠道優勢

- 你本身就喺學校，學生係現成嘅測試群組
- 學校 Well-being 政策係大趨勢，你嘅工作有制度支持
- 零獲客成本（CAC = 0）

## 四、90 天實戰計劃

### Phase 1：校內免費測試（第 1-30 日）

**目標：10 個學生用過，收集真實反饋**

**第 1 週：技術部署**

- 將 MVP 部署到學校內網或 GitHub Pages（免費）
- 準備一個 QR Code，學生掃碼即開
- 測試：確保學校 WiFi 可以訪問

**第 2 週：小規模試玩**

- 揀一個視藝班（你本身教嘅班）
- 課堂最後 15 分鐘：「今日我哋試下一個新嘢」
- 學生掃 QR Code → 選場景 → 畫 5 分鐘 → 講感受 → 生成卡片
- **你唔需要額外排工作坊，融入現有課堂**

**第 3-4 週：收集反饋**

- 每個用完嘅學生填一份 3 問卷：
  1. 畫嘅過程開心指數 1-10？
  2. 會唔會想再玩？（是/否）
  3. 有乜嘢想改進？
- 記錄：邊個場景最多人揀、平均畫幾耐、語音使用率

**時間投入：每週 2-3 小時**

- 課堂內 15 分鐘（已有時間，唔使額外準備）
- 課後 30 分鐘整理反饋

---

### Phase 2：擴大測試 + 第一個收入（第 31-60 日）

**目標：30+ 學生用過，開始有付費意願數據**

**行動：**

1. 擴大到 2-3 個班（你教嘅班 + 同事嘅班）
2. 根據 Phase 1 反饋優化 MVP（改 UI、加場景、調解讀文字）
3. 推出**家長版工作坊**（學校 Well-being 活動）：
   - 時間：學校開放日 / 家長日其中一個環節
   - 內容：30 分鐘正念繪畫體驗
   - 收費：免費（學校名義舉辦）
   - **目的：收集家長反饋，建立口碑**
4. 小紅書內容啟動：
   - 每週 1-2 篇（用課堂真實素材，匿名化）
   - 主題：「學生用畫筆表達壓力」系列
   - **唔需要完美，真實就有價值**

**時間投入：每週 3-4 小時**

---

### Phase 3：決定下一步（第 61-90 日）

**根據數據決定：**

| 如果...           | 做...                    |
| ----------------- | ------------------------ |
| D7 留存率 > 30%   | 推出 B2B 學校年費方案    |
| D7 留存率 < 30%   | 分析原因，優化產品或轉向 |
| 有家長/學校主動問 | 開始規劃付費版本         |
| 沒有反饋          | 停止投入，轉向其他方向   |

**可能嘅下一步（如果數據支持）：**

- 付費版：HK$78 買斷 / $18 月租
- B2B 學校授權：HK$8,000-12,000/年
- PDF 電子書：正念繪畫教學指南

## 八、風險與應對

| 風險         | 應對                                                             |
| ------------ | ---------------------------------------------------------------- |
| 學生唔感兴趣 | 先觀察，唔好強推。如果 3 個班都冇人想玩，可能方向要調            |
| 學校唔批准   | 用「課堂教學活動」名義，唔係「額外工作坊」。你本身有課程自主權   |
| 隱私問題     | 純前端運算，唔收集任何學生數據。v1 完全 offline                  |
| 醫療合規     | 唔用「治療」「療癒」字眼。定位為「正念繪畫練習」「情緒表達工具」 |
| 時間唔夠     | 嵌入現有課堂，唔搞額外活動。零額外時間成本                       |

## 九、成功標準

**90 日後，如果以下任一條件成立，就值得繼續：**

1. 有學生主動問「幾時再畫？」
2. 有同事問「可唔可以用喺我個班？」
3. D7 留存率 > 20%
4. 有家長表示有興趣

**如果全部冇發生，誠實停損，轉向其他方向。唔好因為已經投入咗時間就繼續燒。**
