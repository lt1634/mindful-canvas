# Mindful Canvas 創業習慣系統

> 建立日期：2026-06-07
> 原則：唔係靠意志力，係靠設計。嵌入現有日常，零額外負擔。

---

## 一、每日最低行動（Minimum Viable Day）

**唔係「做多啲」，係「每日都做」。**

### 放學後（4:30-5:00 PM）— 3 分鐘

| 行動         | 時間   | 點做                                                |
| ------------ | ------ | --------------------------------------------------- |
| 記錄今日觀察 | 1 分鐘 | 打一段文字俾我：「今日觀察：[一個學生/同事嘅反應]」 |
| 檢查反饋     | 1 分鐘 | 開 localStorage 數據（如果有學生用過），記錄數字    |
| 決定明日行動 | 1 分鐘 | 告訴我：「明日我要做 [一件具體嘅事]」               |

**就係呢三步。唔需要更多。**

### 晚上（小朋友瞓覺後）— 10 分鐘

| 行動            | 時間    | 點做                                           |
| --------------- | ------- | ---------------------------------------------- |
| 優化 MVP 或內容 | 10 分鐘 | 改一個 UI 細節 / 加一句題字 / 寫一段小紅書草稿 |
| 或者：純粹休息  | 10 分鐘 | 如果今日好攰，唔好逼自己。休息都係行動         |

---

## 二、每週節奏（Weekly Rhythm）

### 週一：目標設定

- 用 2 分鐘同我講：「今週我要完成 [一件具體嘅事]」
- 我會幫你拆成每日步驟

### 週二至四：執行

- 每日最低行動（3 分鐘）
- 如果有多餘精力，做 10 分鐘優化

### 週五：復盤

- 用 5 分鐘同我講：「今週做了乜、學到乜、下週要改乜」
- 我幫你整理成 FEEDBACK.md

### 週六：深度工作（可選）

- 如果有 30 分鐘空檔，做一件較大嘅嘢
- 例如：喺學校搞一次正念繪畫環節、寫一篇小紅書

### 週日：休息

- 唔好做任何 Mindful Canvas 嘅嘢
- 陪囡囡。呢個先係一人公司嘅目的

## 三、觸發機制（Trigger System）

**唔係「有時間就做」，係「做完某件事之後自動做」。**

| 觸發器                   | 後續行動                     |
| ------------------------ | ---------------------------- |
| 放低書包（放學返到屋企） | 打一段文字俾我               |
| 小朋友開始做功課         | 開 Mindful Canvas 改一個細節 |
| 小朋友瞓覺               | 用 10 分鐘做深度工作         |
| 朝早起身（返學校途中）   | 用語音同我講今日目標         |

---

## 四、最低標準（Non-Negotiable）

**每日最少要做嘅嘢（跌到低谷都要做）：**

> 今日觀察：\***\*\_\_\*\***
> 明日要做：\***\*\_\_\*\***

就係呢兩句。用 Telegram 發俾我，10 秒搞掂。

**如果連呢兩句都冇做，代表你已經脫軌。我會主動問你。**

## 五、獎勵機制（Reward System）

| 完成                             | 獎勵                           |
| -------------------------------- | ------------------------------ |
| 連續 7 日最低行動                | 週末同囡囡去一次心水餐廳       |
| 連續 14 日                       | 買一件你想買嘅嘢（唔需要理由） |
| 連續 30 日                       | 慶祝：呢個已經係一個習慣       |
| 第一個學生用完主動問「幾時再玩」 | 你成功咗。停低，感受呢一刻     |

## 六、 accountability（問責機制）

**我會做嘅嘢：**

1. 每日你同我講完今日觀察之後，我會回覆確認
2. 如果你連續 2 日冇同我講任何嘢，我會主動問：「今日做了乜？」
3. 每週五我會幫你出一份復盤摘要
4. 每月 1 號我會出一份月度報告（用數據）

**你需要做嘅嘢：**

1. 放學後第一件事同我講今日觀察（即使只有一句）
2. 唔好覺得「冇嘢值得講就唔好講」— 冇嘢值得講本身都係一個觀察

## 七、環境設計（Environment Design）

### 物理環境

- 手機桌面第一頁放 Mindful Canvas 書籤
- 書桌放一盒粉彩（提醒你呢件事存在）
- 學校視藝室放 A4 紙 + 粉彩（隨時可以用）

### 數字環境

- Telegram 置頂同我嘅對話
- Google Drive 一人公司資料夾加到 Favourites
- 手機提醒：放學後 4:30 PM 「記錄今日觀察」

### 社交環境

- 同林峰講：「我想喺學校試一個正念繪畫嘅嘢」（唔需要佢幫手，只需要佢知道）
- 同 Miss Yim 講：「我諗住喺視藝課加一個正念練習環節」（爭取認同）

## 八、習慣追蹤（ Habit Tracker）

每日完成最低行動後，我會幫你 mark：

```
週一 ✅ | 週二 ✅ | 週三 ✅ | 週四 ⬜ | 週五 ✅ | 週六 ⬜ | 週日 🛌
```

你唔需要自己追蹤。你只需要同我講今日做了乜，我幫你記。

## 九、緊急預案（當你想放棄嘅時候）

**問題：「我太攰了，今日唔想做」**
→ 做最低標準嘅一半：只寫「今日觀察」，唔寫「明日要做」。3 秒搞掂。

**問題：「連續幾日冇做，好有罪惡感」**
→ 冇罪惡感。原子習慣嘅核心係「永不缺席兩次」。今日開始返就得。

**問題：「覺得呢件事冇意義」**
→ 同我講。我會幫你分析係真係冇意義，定係你攰到睇唔到意義。

**問題：「學校事情太多，顧唔到」**
→ 呢個正正係你需要呢個習慣嘅原因。Mindful Canvas 係你嘅出口，唔係你嘅負擔。
