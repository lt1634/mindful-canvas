# VIX 高位入市框架

> 原則：別人恐懼時貪婪，但要有紀律、有準備、有安全邊際。

---

## 一、VIX 基礎知識

| VIX 水平 | 市場情緒 | 操作指引             |
| -------- | -------- | -------------------- |
| < 12     | 極度自滿 | 唔加倉，開始警惕     |
| 12-16    | 正常     | 正常持有             |
| 16-20    | 輕微緊張 | 留意，準備現金       |
| 20-25    | 恐慌開始 | 分批觀察             |
| 25-30    | 恐慌     | 第一注入貨           |
| 30-40    | 極度恐慌 | 第二注入貨           |
| > 40     | 恐慌見頂 | 全力入貨（歷史罕見） |

---

## 二、入市先決條件（三個都要滿足）

**條件 1：用閒錢**

- 唔好動用孖展（融資）
- 唔好動用生活費
- 唔好動用 6 個月內需要用嘅錢
- **最低標準：呢筆錢消失咗，你嘅生活唔受影響**

**條件 2：買大盤指數**

- ✅ VT（全球股票）
- ✅ 2834 / QQQ（納指 100）
- ✅ 3110（恒生高息）
- ❌ 唔好買個股（跌咗可能唔返）
- ❌ 唔好買杠杆產品

**條件 3：分批入貨**

- 唔好一次過 all-in
- 分 2-3 注，每注間隔 3-7 日
- 如果繼續跌，加倉；如果反彈，停止

## 三、入貨信號（VIX 高位 + 以下任一條件）

| 信號                     | 說明                   |
| ------------------------ | ---------------------- |
| VIX > 25 且連續 3 日     | 恐慌已持續，非一時情緒 |
| 美債收益率回落           | 鷹派預期降溫           |
| VIX 從高位回落 20%       | 恐慌見頂開始消化       |
| 大盤跌 > 10% 後企穩 3 日 | 技術面確認底部         |
| 你嘅現金已到位           | 條件 1 滿足            |

## 四、操作流程

```
VIX > 25
    │
    ▼
檢查：有冇閒錢？ → 冇 → 等
    │
    ▼ 有
檢查：買嘅係指數？ → 冇 → 換成指數
    │
    ▼ 係
第一注：30% 資金
    │
    ▼
等 3-7 日
    │
    ▼
VIX 繼續升 / 股市繼續跌？
    ├─ 是 → 第二注：40% 資金
    └─ 否 → 觀望
    │
    ▼
再等 3-7 日
    │
    ▼
VIX 回落 > 20% / 大盤企穩？
    ├─ 是 → 第三注：剩餘 30%
    └─ 否 → 暫停，重新評估
```

---

## 五、紀律規則

1. **唔好接飛刀** — 大跌第一日唔好買，等 1-2 週
2. **唔好估底** — 冇人知道底部喺邊，分批就係承認自己唔知
3. **唔好加槓桿** — 恐慌市加槓桿 = 自殺
4. **買完唔好睇盤** — 至少 3 個月唔好因為跌咗就賣
5. **設定停損** — 如果整體倉位跌 > 25%，暫停加倉，重新評估
6. **記錄每一次操作** — 記錄買入日期、價格、VIX 水平、原因
